## Evaluation Methods

### 1. Deterministic Assertions (EV02)
- Intent classification match
- Expected tool called
- Chart position tolerance (±0.5°)
- JSON schema validation (pydantic)
- Error case response keyword matching

### 2. LLM-as-Judge (EV03)
- Applied to 7 cases with reference answers
- Scores warmth (1–5) and helpfulness (1–5)
- Temperature=0 for reproducibility
- Validated against human_judgement.json (≥80% agreement threshold)

### 3. Cost / Latency / Failure Metrics (EV04)
- Logged per-case: tool calls, tokens, cost, latency
- CSV output to results/
- Markdown scorecard auto-generated

### 4. Failure-Mode Tests (EV05)
- 8 explicit error cases covering invalid dates, missing data, prompt injection, and out-of-scope
- Assertions on exact fallback phrase keywords

## Notes for Future Engineers

- If the backend uses a non-standard port, set `ASTROAGENT_BACKEND_URL` env var
- Golden set uses real cities (New York, London, Tokyo, Paris, etc.) — Nominatim rate limits apply; run sequentially
- Sentence-transformers downloads `all-MiniLM-L6-v2` on first launch (~80 MB)
- pyswisseph data is bundled in the Python package; no external ephemeris files needed
- Add new cases to `eval/golden_set.jsonl` — format is self-documenting
- The judge validation threshold (80%) is configurable in `eval/run.py`
